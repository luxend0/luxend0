- [testux](https://github.com/luxend0/testux) - try Linux distros in a window, then boot the live ISO without a USB stick (Qt 6, QML, C++)
- [kammzeit](https://github.com/luxend0/kammzeit) - open-source appointment booking for hair and beauty salons (Go, SQLite)
- [luxshell](https://github.com/luxend0/luxshell) - Quickshell desktop shell for Hyprland with a dynamic island
- [server-tools](https://github.com/luxend0/server-tools) - 72 small dev and admin web tools (React, Node)
- [gh-statcard](https://github.com/luxend0/gh-statcard) - the stats card above, one static SVG, no server needed
